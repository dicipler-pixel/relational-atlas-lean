This ledger records evidence for every card B1–B207. A source grade of THEOREM is not itself a Lean certificate. A mapped kernel proves only the linked Lean declaration under its written hypotheses; no complete-card certification is assigned by this audit. Missing mappings mean not yet mapped in the audited scope, not that no proof exists anywhere.
